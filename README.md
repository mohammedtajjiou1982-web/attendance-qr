# تطبيق حضور التلاميذ QR — مشروع Android

هذا مجلد مصدر لبناء تطبيق Android بصيغة APK عبر Android Studio. ليس ملف APK جاهزاً للتثبيت.

## المتطلبات
- حاسوب Windows أو macOS أو Linux
- Node.js LTS
- Android Studio مع Android SDK

## خطوات البناء
1. فك ضغط الملف.
2. افتح مجلد المشروع في Terminal / PowerShell.
3. نفّذ:
   ```bash
   npm install
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
4. في Android Studio انتظر اكتمال Gradle Sync.
5. من قائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
6. سيظهر مسار ملف APK داخل نافذة Android Studio.

## صلاحية الكاميرا
بعد إنشاء مجلد android، افتح:
`android/app/src/main/AndroidManifest.xml`
وأضف قبل وسم `<application>`:
```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-feature android:name="android.hardware.camera" android:required="false" />
<uses-permission android:name="android.permission.INTERNET" />
```
تأكد من السماح للتطبيق باستخدام الكاميرا عند أول تشغيل.

## ملاحظات مهمة
- النسخة الحالية تستخدم مكتبات QR من الإنترنت (CDN)، لذلك يلزم اتصال بالإنترنت عند فتح التطبيق لأول مرة واستخدام المسح/توليد QR.
- البيانات محفوظة محلياً داخل التطبيق على نفس الهاتف؛ حذف التطبيق أو بياناته قد يؤدي إلى فقدانها. صدّر ملفات CSV بانتظام.
- هذا المشروع لم يُبنَ أو يُختبر على هاتف فعلي بعد. يلزم بناء APK وتجربته قبل اعتماده في المؤسسة.

## النسخ الاحتياطي
- افتح تبويب «النسخة الاحتياطية» داخل التطبيق.
- اضغط «إنشاء نسخة احتياطية JSON» لحفظ ملف يحتوي قائمة التلاميذ وسجلات الحضور.
- لاسترجاع البيانات، اختر «استرجاع نسخة JSON» وحدد الملف السابق.
- توجد نسخة داخلية يومية في تخزين التطبيق، لكنها لا تحمي من حذف بيانات التطبيق؛ احتفظ دائماً بملف JSON خارجي.

## تحميل لائحة التلاميذ بصيغة Excel
من تبويب «التلاميذ و QR» اضغط «تحميل لائحة التلاميذ Excel». ينشئ البرنامج ملف XLSX يحتوي الترتيب ورقم التلميذ والاسم الكامل والقسم. يلزم اتصال بالإنترنت لتحميل مكتبة Excel؛ وإذا تعذر تحميلها ينشئ ملف CSV متوافقاً مع Excel.

## استيراد لائحة التلاميذ من Excel
- افتح تبويب «التلاميذ و QR» ثم اضغط «استيراد لائحة التلاميذ Excel».
- اختر ملف XLSX أو XLS أو CSV. يجب أن تكون الأعمدة في الورقة الأولى: «رقم التلميذ»، «الاسم الكامل»، «القسم».
- يضيف البرنامج التلاميذ الجدد فقط ويتجاوز أرقام التلاميذ الموجودة مسبقاً، ولا يحذف أي بيانات.
